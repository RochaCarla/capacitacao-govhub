## Objetivo
Garantir que a navegação por teclado siga a ordem lógica do layout, e não a ordem em que os visuais
foram criados.

## Antes de começar
- Power BI Desktop instalado.
- O layout da página finalizado — mudar visuais depois altera a ordem.
